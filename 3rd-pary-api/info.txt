3rd Party API - OpenWeatherMap Weather App

1. Install dependencies:
npm install

2. Run development server:
npm run dev

3. Build production bundle:
npm run build

- Endpoint: https://api.openweathermap.org/data/2.5/weather?q={city}&units=metric&appid={API_KEY}
